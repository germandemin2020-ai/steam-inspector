# ⚡ Steam Universal Inspector & Inventory Checker

> **Универсальный аналитический веб-сервис для аудита любых профилей Steam, оценки инвентарей CS2 / Dota 2 / TF2 и дуэльного сравнения с друзьями (VS Battle Mode).**

Разработано в эстетике киберспортивных платформ (SteamDB / CSFloat / HLTV).

---

## 🚀 Основные возможности

### 1. 🔍 Универсальный поисковик & авто-резолвер
- Поддерживает **любые форматы ввода**:
  - `https://steamcommunity.com/id/ohnePixel/`
  - `https://steamcommunity.com/profiles/76561198045277210/`
  - Короткие ники: `ohnePixel`, `s1mple`, `gabelogannewell`
  - 17-значный SteamID64: `76561198045277210`
- Автоматически резолвит Vanity URL в постоянный SteamID64 через Steam Community XML.

### 2. 🎒 Инспектор инвентаря CS2, Dota 2, TF2
- **Если инвентарь открыт:**
  - Зеленый статус `[ 🔓 Инвентарь открыт ]`;
  - Подсчет общего количества скинов и расчетная стоимость в рублях и долларах;
  - Сетка HD-скинов с официальными цветами редкости (Тайное, Засекреченное, Ножи/Перчатки);
  - Интерактивный поиск по названию, фильтр редкости и сортировка от дорогих к дешевым.
- **Если инвентарь закрыт:**
  - Четкий бейдж `[ 🔒 Инвентарь скрыт настройками приватности Steam ]`;
  - Без крашей и пустых экранов;
  - Профиль игрока (уровень, значки, стаж, игры, статус VAC) отображается в полном объеме!

### 3. ⚔️ VS Mode («Сравнить с другом»)
- Экран дуэли двух профилей:
  - Сравнение стоимости инвентарей;
  - Сравнение уровня Steam;
  - Сравнение количества предметов и игр;
  - Сравнение стажа аккаунта;
  - Золотой бейдж победителя 👑 по каждой категории.

### 4. ⚡ Демо-пресеты в 1 клик
- **💎 Коллекционер (Открытый инвентарь):** `ohnePixel` (795+ предметов, ножи, перчатки);
- **🔒 Приватный инвентарь:** демонстрация детектора скрытых инвентарей;
- **⛔ Профиль с VAC-баном:** демонстрация детектора читеров и блокировок.

---

## 🛠 Технический стек

- **Backend:** Python 3.12, Flask, Requests.
- **Frontend:** Tailwind CSS, Glassmorphism, Lucide Icons, JetBrains Mono & Inter.
- **Кэширование:** Встроенный in-memory кэш (TTL 5 мин) для обхода лимитов Steam (HTTP 429).
- **CORS-защита:** Локальный сервер выступает прокси, исключая блокировки браузера.
